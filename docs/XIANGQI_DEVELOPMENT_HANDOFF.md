## 本轮边界与优先级

用户已确认进入开发。Codex 已制作棋盘、棋子、腰挂勺挂点和16段动作，完成独立预览与素材检查。DeepSeek 负责正式游戏逻辑、服务端棋规、前端交互、寻路/执行器、LLM工具和异常恢复。**素材页不是已实现的象棋游戏**；本轮没有部署游戏，也没有改动生产角色加载常量。

资料冲突时：用户最新决定 > 本交接与配套正式方案 > 当前 catalog/曲线中的素材参数 > 旧方案或历史进度。实际素材数值以 catalog 为准；如其与已确认外观冲突，应先指出差异，不自行缩放补救。

## 工具、快照与资源契约

新增可执行动作，字段进入实际能力注册表、工具Schema、服务端校验、前端协议与执行器；不能仅修改提示词。

| action | 参数与前置条件 |
| --- | --- |
| `stow_scoop` | 无业务参数；右手持饭勺、右腰槽空、站定、未抱棋 |
| `unstow_scoop` | 无业务参数；右腰有饭勺、右手空、站定、未抱棋 |
| `xiangqi_move` | `game_id:string`、`piece_id:string`、`to_row:integer[0,9]`、`to_col:integer[0,8]`、`expected_revision:integer>=0`；己方回合、合法目标、双手空、无冲突pending |

`moveId`由宿主基于task/plan/step稳定生成；重试复用原ID，不能每次重试生成新的一着。服务端返回单次授权token，绑定gameId、pieceId、源/目标、revision、任务generation与执行页leaseEpoch，token不由LLM编造。

- 抱棋占用`body_locomotion`、双臂和该棋子；不能与walk/run/手势/挂取勺/敲盆并行。随机漫游服从同一锁，不能偷走根位移。
- 一个棋子只有一个owner/公共锚点；双手资源都被保留，不给同一Object3D设两个parent。建议显式`both_hands`逻辑持有状态。
- 挂腰后`right_hand`真正空闲；腰勺仍显示，不能直接在腰间执行敲盆/挖掘/投掷。先取回。
- 快照包含棋局ID/规则集/执色/回合/revision、稳定pieceId及row/col、合法候选、将军/结果/最近棋步、pending阶段与真实物体位姿、装备槽位、租约与暂停原因。
- 成功结果包含`committed:true`、moveId、最新revision、吃子ID/终局结果；失败包含稳定错误码、是否可重试、pending状态、是否已提交。`animation_finished`不是`committed`。

## 实现顺序与每批验收

1. **资产与模式骨架。** 用新副本载入旧45+新16段；保留眨眼/盆勺；切换场地/物理边界/相机/导航参数和公开状态；退出正确恢复。先在独立执行器里验证挂取勺及空手抱持。验收页继续保留用于对照。
2. **规则与权威服务。** 合法着法、将军/终局、CCA2020棋例和历史裁决；开局执色、幂等moveId、revision、授权、持久化/公开状态。未逐例通过前标测试版，不宣称完整标准棋规。
3. **用户交互。** 选子悬停、两种目标提示、鼠标/触屏取消与拖动排除、弧线与吃子、结算/表现锁、重连恢复。不能用客户端高亮结果代替服务端校验。
4. **角色搬运。** 近距离站位、魔法飞入、持棋走/停/转向/短步、送出等待ACK、落座与吃子；连同装备槽、资源锁与物理障碍一起接入。默认参考站距0.85米，不能沿用普通慢走0.09+0.18n的距离直接覆盖专用节奏。
5. **LLM闭环。** 注册新工具和条件提示词；开局轮到角色或用户一着完成后才触发她走下一着。自己的棋步提交后review核实结果，轮到用户就等待，不连续替双方走子。闹钟后恢复先对账。
6. **故障与回归。** 中途抢占、源/目标飞行、吃子等待点、ACK丢失、提交后回执丢失、重复回执、旧generation/租约、刷新、多标签、结束/换局；扫雷/五子棋/盆勺/聊天/定时器回归，再按版本管理文档提交、推送和部署。

每批在方案中更新真实状态和证据。不要将素材验证报告改写成正式游戏测试结果。

## 关键实现细节

- `prop_motion.json`是角色局部参考曲线；地面源/目标要从权威交点和真实物体位置计算。约0.85米站位对正后再播放，开头不能把原棋子瞬移到参考点。捕获当前姿态，平滑衔接。
- 棋面朝向按红黑布局；吸附/换parent需保留world变换并处理旋转偏移，不能因角色朝向不同在抓取时瞬转180°。
- 抱持锚点底高约0.32235米、棋子中部/掌部约0.45米；静止棋子顶高0.2553米。素材报告中的约6.7厘米余量只描述参考姿势，不能据此让身体穿过地面棋子。
- 地面相邻棋子净隙仅约0.228米，角色不能硬挤；按身体/裙摆/尾巴/腰勺轮廓搜可达站位和绕行路线。先试其他接近角/外侧路线；找不到路返回可恢复失败，不谎报成功、不推移其他棋子、不让合法棋步永久静默失效。密集后续局面需要专门验收。
- 放置在0.4秒释放，双手此后已空；1.2秒落稳等待提交。吃子在1.1秒悬停于敌子上方等待提交；确认删除敌子后才继续下降。身体与道具共用可暂停时钟；不能用setTimeout代替ACK。
- 到达等待点后重复/超时消息要对账；若已提交，只完成表现收尾，不能回滚合法已提交的一着或再吃一次棋子。
- 任意行走相位收到最高优先级事件，先撤销旧回调和位移，受控稳定脚与道具，再做安全放置；**静态入口的safe_setdown不能直接硬切任意半步**。这部分由宿主实现并实测，不是现成动作包已经解决。
- 棋局结束、取消、换游戏、结束页租约时，收束pending和占用，释放表现锁；已被吃棋子的模型、障碍、射线命中与快照统一删除。
