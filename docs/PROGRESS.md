## 2026-11-01 ~ 11-03 的改动

1. **移动统一为坐标接口**：模型只说 `move_to(x,y,z)`，执行器自选走/慢走/跑并处理转向与收步；`move_to` 目标受场地范围约束。
2. **抱棋改为分层组合**：取消专用抱棋走跑基底，改用普通移动片段 + `chessPose`（躯干与双臂）覆盖层；尾巴、头部保持独立，握棋时拒绝需要手臂的手势。见 [MOTION_COMPOSITION_2026-11-01.md](MOTION_COMPOSITION_2026-11-01.md)。
3. **阴影角落修复**：`src/core/shadowBounds.ts` 把场地 8 个角投影进光照相机求包围盒，11.5m 场地 extent 8.12，角落不再没影子。
4. **正面小窗**：`src/ui/PortraitWindow.ts` + `portraitCamera.ts`，同一 WebGL 上下文用 scissor 视口渲染，宽度跟随左侧栏，角色占框约 89%。
5. **终局棋谱保留**：分出胜负后 `moveHistory` 一直留在提示词里，直到用户收摊或换局；`xiangqiEnded` 条件段落只说明"已结束、别继续走子"。
6. **放子不再"端一下"**：`release` 事件即 `setCarrying(false)`，抱棋姿态残留从 44 次降到 0。
7. **提示词缓存布局**：棋谱移出上下文 JSON，改为尾部独立块 `XIANGQI_MOVE_HISTORY_JSON`；每轮都变的快照放最后。走一手后的公共前缀从 39.8%（仅挪棋谱）提升到 **97–98.6%**。详见 [PROMPT_CACHE_LAYOUT.md](PROMPT_CACHE_LAYOUT.md)，回归在 `tests/prompt-cache-order.test.mjs`。
