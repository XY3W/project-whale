# V9 后续动作制作规范

## 固定基线

从 V9 EDITABLE 的新副本制作，保留原件。运行时使用 v9-anatomical-baked-1 公共骨架，不将旧 GLB 动作直接挂到源 376 骨静态导出上。新增动作须重新走完整烘焙与回读验证。

## 制作

1. 清空上一动作影响，建立共同站姿：双臂下放 48°，前臂向前 12°；手臂 FK，腿部 IK，自动拉伸关闭，所有面部参数为零。
2. 用控制器制作，保留源 rig 的约束计算；不要直接旋转最终变形骨来绕开扭转、拉伸或颈部依赖。
3. 作者坐标为 Blender +Z 向上、-Y 朝前。世界轴旋转须用静止骨局部旋转共轭转换：q_local = inverse(q_rest) · q_world · q_rest。不要把世界轴角度直接写到骨骼局部 Euler。
4. 头颈左右看本批为 8° + 2°，点头为 5° + 2°；这只是已验证动作范围，不是所有姿态下的通用极限。
5. 尾巴只调整 01–06，根骨保持骨盆锚定；本批每节约 1.2° 或 3° 基准幅度，带小幅相位延迟。增大幅度必须复查裙摆、头发、地面与尾根。
6. 曲线先用平滑缓入缓出，30 fps 采样后用线性插值，避免额外 Bezier 过冲。循环末帧与首帧一致；发布播放器依照时长循环。

## 烘焙和导出

先完整求值，再按固定 83 骨运行时层级烘焙局部 TRS。独立前臂、手、扭转辅助骨挂到稳定躯干祖先，脚与裙骨挂到骨盆；这一步只发生在运行时副本。每个动作比较源蒙皮与烘焙蒙皮世界坐标，不能把网格局部坐标直接乘骨架空间矩阵。

GLB 必须携带全部权重组；不要以“Three.js 默认只有四组分量”为由直接截断。保留未切分完整 GLB 供回读测试，再按 tracks 清单生成 lower / upperBase / upper / tail。所有 upper 片段必须拥有相同完整上身轨道集，包含受约束辅助骨的位置和缩放，不能只保留旋转。

## 播放约束

基础上身与手势上身使用互补权重。默认禁止 additive；若将来引入，必须定义统一参考姿态和差值生成过程。上身结束后恢复当前基础上身，不复位整个角色。尾巴根骨不属于自由摆尾层。没有通过组合测试的动作不能自动标记为任意兼容。

步行起停必须使用已制作的过渡片段和配套位移曲线。不能对整体身体动画任意缩放幅度；允许倍率 0.75–1.25，但脚步时间与世界位移必须同时缩放。转向目前采用先停稳的策略；另作转身片段后才能承诺脚部无滑动转向。

## 验收顺序

- 正面、侧面、背面检查头颈、领结、腋下、手腕、裙摆、尾根。
- 原生蒙皮与烘焙副本对比；再做 GLB 导出回读，身体和尾巴分别记录误差。
- 检查循环首尾、起步、收步、支持脚世界位移，变速至少覆盖 0.75 / 1 / 1.25。
- 测试 walk + greet + tail、手势排队打断、循环切换及恢复基础动作。验证的不只是单个片段。
- 用浏览器真实加载，校验全部权重和，观察阴影与法线，再执行构建和 runtime 验收脚本。
