# V9 动作库与领结修复

基于 V8 新建副本，原模型保留。交付 10 个用户动作，以及 2 个慢走内部过渡动作。本文说明实际交付与验证范围，不代表远端部署。

## 文件

- `Character_Animation_v9_EDITABLE.blend`：376 骨源控制器绑定，局部领结权重修复，可继续制作动作。
- `Character_Animation_v9_BAKED.blend`：83 骨公共运行时骨架，所有变形结果烘焙为局部位置、旋转、缩放，不依赖 Blender 约束。
- `character_v9.glb`：正式分层包，身体与尾巴均保留，全部原始影响权重。12 个动作映射为 16 个实际播放片段（4 个 base 各拆两层）。
- `character_v9_full.glb`：未切层的完整烘焙中间产物，用于对照，不要整身混播。
- `catalog.json` / `tracks.json` / `manifest.json`：动作元数据、节点与属性归属、版本和 SHA-256。
- `scripts/`：本次制作、烘焙、导出、验收脚本；`research/`：原始验证数据。
- `previews/`：各动作正面、侧面、背面静帧及动态预览；领结修改前后特写。

## 修复内容

领结核心区域 601 个顶点改为胸部 spine_05 锚定，边缘采用 10 毫米空间渐变，消除头颈和肩臂对领结的拉扯。没有改变身体顶点位置、原有静止骨架或尾巴造型。权重变更范围与原值见 research/weight_edit.json。

对相同左右看姿态，修复前领结核心边长比约 0.533–1.622；修复后接近 1。步行、挥手与摆尾组合中仍保持完整。此结论针对交付动作范围，并非承诺任意极端姿态都安全。

运行时骨架按解剖关系挂接独立辅助骨，完整烘焙扭转/拉伸结果。源模型原控制器绑定不变。浏览器完整保留最多 16 个权重；加载器从原始 buffer 恢复第一组权重，同时处理法线、切线和阴影蒙皮。

## 接入要点

使用项目 `src/character/LayeredMotionPlayer.ts` 和 `multiWeight.ts`。直接加载本包公共骨架与 clips；不要再加载旧 pose-reference，不要逐帧还原骨骼，也不要叠加旧 Idle/Gesture/TailController 的骨骼旋转。

base 的 lower 与 upperBase 同相位播放。手势上身与基础上身互补权重；腿部不受挥手影响。尾巴单独循环，WhaleTail_Root 属于基础下身，保持骨盆锚定。停止手势只恢复基础上身，不停止慢走。

世界移动必须累加 `player.movementDelta`，不能另设独立于片段的速度。默认前进方向为 glTF +Z。慢走循环步长 0.09 米、步幅 0.18 米、标定速度 0.1125 米/秒。起步距离为 0.045·u²，收步距离为 0.045·(2u-u²)，u 为该过渡片段的归一化时间；执行器已实现。

停止指令会等到下次左脚着地再收步，1 倍速最久约 2.4 秒；这是保持支撑脚稳定的明确取舍。紧急停止、任意路径转弯、楼梯、斜坡不在本动作库范围。转身应先停稳，再由独立转身方案处理，不能在站立支撑时直接急转根节点。

## 验证

- 原生姿态：循环首尾一致，领结核心无明显拉伸，尾端保持离地。
- 烘焙与 GLB 回读：12 个动作均验证身体与尾巴，最大顶点误差低于 0.03 毫米。
- 实际 Three.js 动画混合：上身手势不改变下身世界矩阵，手势结束恢复慢走，排队打断与循环切换通过。
- 起步—循环—收步：0.75 / 1 / 1.25 倍速支撑脚骨逐帧位移最大约 0.017 毫米。该数值是骨骼运动轨迹指标，不等价于鞋底每个顶点的精确地面接触或完整碰撞求解。
- 浏览器：模型与组合动作显示正常，三组身体材质全部权重归一和误差小于 2e-7，无加载错误。
- `npm run build` 通过；`node scripts/animation-v9/validate-runtime.mjs` 可复跑组合验收。

## 范围与限制

眨眼与其他损坏形态键仍按一期设计禁用；源文件保留形态键，运行时不导出。没有新增跑步、坐下、跳跃，也没有接入 LLM 或部署服务器。

本次新增独立动作验收页 `/animation.html`，主页面增加入口，旧主场景的行为系统尚未整体迁移到新播放器。验收页支持各动作、组合、正侧背观察与向前走；观察不会自动转身。
