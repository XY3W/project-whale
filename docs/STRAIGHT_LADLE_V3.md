## 更新范围

木纹、金属材质、握点和角色原身材保留。杆中心线偏离木柄轴为 0；勺体整体绕接合点旋转，勺口朝向和圆形深勺体一起变化。杆轴方向的外形长度约 31.3cm，勺头外径约 10.8cm。

角色 GLB、39 段动画、手部绑定矩阵及 tracks 均不变。minesweeper-v1 的 74 个文件和木柄弯杆 v2 的 32 个文件校验值均保持一致；v2 留作历史版本，当前应使用 v3。

## DeepSeek 接入

本包仍基于 minesweeper-v1。原子应用三个运行文件：

- `rice_scoop_straight_v3.glb`：新勺模型，木纹内嵌。
- `catalog.json`：新的模型引用、拾取参考姿态、勺口法线、挖掘效果点和碰撞代理候选。
- `prop_motion.json`：正反两种落地姿态的完整拾取轨迹。

其余角色、盆和动作文件沿用基线。可从 v1 或 v2 接入此增量；不要混用 v2 的模型/曲线/落地参考。物品 ID 仍是 rice_scoop，先等当前物品动作安全结束，再切换资产版本和缓存。

**不能继续假设勺口朝向是模型局部 +Y，也不能只检查杆是否平行于地面。** 读取 `bowlOpeningNormalLocal` 判断勺口方向，并使用 `pickupVariants` 的完整参考旋转和位置判定支持姿态。现在的两个落地参考分别带约 -3.65°、+17.60° 的杆俯仰，原点离地约 15.90mm、24.13mm。精确数据以 catalog 为准，不要手填这些四舍五入值。

拾取身体动作和事件时刻不变（0.48s 挑起、1.18s 接住）；起点与轨迹按新勺体重新适配，不能在挑起时把物品吸到旧参考点。挖掘效果点也移到倾斜后的勺头位置。侧立或其他不匹配姿态仍需返回不支持，不自动摆正。

碰撞代理已经按直杆和倾斜勺体的外形更新，仍是供引擎验证的粗略候选。实际反弹、休眠、恢复、可拾取姿态匹配仍由 DeepSeek 接入验收，未在本次修改服务器代码。方案、预览和 .blend 继续留本地。
