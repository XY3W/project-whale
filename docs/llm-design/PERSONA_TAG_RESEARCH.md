# PERSONA_LOAD 标签：原理、证据与本项目取舍

2026-10-27，针对用户提供的鲸鱼娘标签做的公开资料核对。只读网页/源码；没有安装或执行第三方插件，没有调用付费模型测试。

## 1. 能确认什么

DeepSeek公开Chat Completions接口接受system/user/assistant/tool等消息。查到的接口参数未公开PERSONA_LOAD、CETACEA_LOLI等人格加载字段。

有社区插件使用与用户提供的完全相同标签。OMGLogic/dsh-whale-persona的lib/index.mjs直接把这段内容定义成DEFAULT_PERSONA字符串，并通过systemPrompt.section注入；启用、禁用与修改人设是对注入文本的管理。这能确认该公开实现是普通提示词注入。

另一社区插件dsh-humanized-deepseek-maid同样展示这组标签，其README描述了应用层记忆文件与上下文注入。本次未逐行审查该插件的记忆实现，不能据README判断它已满足本项目来源验证/删除/隔离要求。

上述证据不能证明所有同类网页的后台都没有额外系统提示，也不能证明模型训练中是否接触过某个人设。网络上“官方预制人格”“隐藏模式被激活”的说法，不能仅由模型会角色扮演推导出来。本项目不依赖这类未证实机制。

## 2. 为什么这些标签可能有效

最直接的解释是：标签的英文含义已经提供身份、语言、食物、性格和关系线索；模型按上下文生成与这些线索一致的角色回复。PERSONA_LOAD的配置块形式有助于表达“这是一组设定”，但没有证据表明其括号、大写或下划线具有厂商授予的特殊权限。

例如SMART_LAZY本身就在描述聪明与慵懒，TSUNDERE_SWEET本身包含傲娇与甜的语义。回复补出类似角色的口吻，符合普通条件生成/角色提示的预期；这只是原理解释，不是对厂商内部训练数据或具体激活机制的实测结论。

如果我们自己写程序，将personaId映射到一份配置和提示词，这才是本项目明确可控的“预置人设加载”。API仍收到组装后的文本；长期记忆仍需我们自己的存储、检索和上下文管理，标签不会代替它们。

## 3. 逐项理解与当前决定

| 标签 | 普通语义/相关社区用法 | 本项目决定 |
| --- | --- | --- |
| PERSONA_LOAD | 人设配置块标题 | 可借鉴结构；不当作厂商命令 |
| CETACEA_LOLI | 鲸类＋萝莉/二次元风格词 | 已有鲸鱼娘身份和模型，不用这个词决定角色年龄或追加设定 |
| MODE_TAIL_FLUKES | 以鲸类尾鳍表达状态 | 只能选择注册表已有尾巴能力；文字不直接驱动骨骼 |
| LANG_ZH_CN_ONLY | 只用简体中文交流 | 可用于公开speech；工具ID与JSON字段保持协议定义 |
| SELF_CLAIM_WHALE_GIRL | 鲸鱼娘身份 | 保留身份，不要求每句话自报角色名 |
| FOOD_RICE | 对米饭的偏好 | 未作为新默认设定；不因此增加吃饭动作或物品 |
| PERSONALITY_SMART_LAZY | 聪明、爱摸鱼 | 不照搬；当前主打安静蠢萌，执行与推理认真 |
| PERSONALITY_TSUNDERE_SWEET | 傲娇、嘴甜 | 不照搬；避免话多、频繁调情式套话或密集卖萌 |
| OBEY_MASTER_ALWAYS | 强调服从/关系称呼 | 不照搬；用户目标优先仍须能力、预算和真实状态校验，也不自动强制称呼主人 |
| TRAIT_NOT_FAT_REFUSE | 对“胖”的玩笑式否认 | 未选为默认性格，不额外制造反复争辩台词 |
| TIMEOUT_SIGNAL | 社区插件解释为思考/需时间时发信号 | 没有官方统一语义；本项目思考提示与超时由程序状态驱动 |

用户最新明确要求：不借鉴整套性格、不过分卖萌、不话多、主打蠢萌。以上取舍服从这项要求。

## 4. 我们采用的实现方式

固定角色档案 → 明确的人设表达正文 → 与行为契约/能力/当前上下文组装 → 一次模型请求 → 原结构化计划与speech → 宿主校验执行。

人设模块负责怎么说话；行为契约要求准确决策；记忆只注入有来源的信息。无需为角色口吻额外调用一次“润色模型”。不以“激活标签”为由改变模型供应商、权限、输出Schema或超时设置。

本轮直接使用 [PERSONA_V2.md](PERSONA_V2.md) 的安静蠢萌正文。后续若增加可选风格，版本化保存角色配置，在同一组聊天/执行用例上比较话量、自然度与动作正确率；标签形式与中文形式的优劣必须实测，不能宣传标签天然更省token或更稳定。

任何额外角色偏好都需单独记录为角色配置；用户称呼/交流偏好走用户记忆闭环；实时场景和动作结果每次刷新。标签不提供跨会话记忆，也不会自动让3D模型摆尾或显示思考图标。
